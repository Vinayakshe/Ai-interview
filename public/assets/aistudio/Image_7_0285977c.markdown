# DESIGN.md - Semantic Design System
## Visual Theme and Atmosphere
- **Aesthetic Direction:** Modern, clean, and minimalist enterprise SaaS with a sleek dark mode atmosphere.
- **Mood / Vibe:** Trustworthy, calm, structured, professional, and high-craft.
- **Surface Treatment:** Dark neutral matte canvas with subtle 1px hairline borders and soft ambient elevation.
## Color Palette and Roles
Colors are structured by visual weight and hierarchy for a refined dark mode experience:
- **Neutral (Canvas / Background - 80-90% of screen):** 
  - `bg-primary`: `#0B0F19` (Deep Slate Dark Canvas)
  - `bg-secondary`: `#1E293B` (Surface Slate)
- **Primary (Core Content / Headings / Body):** 
  - `text-primary`: `#F8FAFC` (Bright Slate White)
  - `text-secondary`: `#94A3B8` (Muted Light Slate)
- **Secondary (Supporting UI / Borders / Dividers):** 
  - `border-color`: `#334155` (Subtle Dark Slate Border)
- **Tertiary (Accents / Interactive CTAs / Focus):** 
  - `accent-primary`: `#2563EB` (Electric Royal Blue)
  - `accent-hover`: `#3B82F6` (Bright Royal Blue)
## Typography Rules
- **Heading Font:** `Inter`, Semi-Bold (600) to Bold (700), tight letter-spacing (`-0.02em`).
- **Body Font:** `Inter`, Regular (400) and Medium (500), line-height `1.5`.
- **Monospace Font:** `JetBrains Mono` for code snippets, IDs, and tabular data.
- **Type Scale:**
  - `H1`: 2.25rem (36px), Line-height 1.2
  - `H2`: 1.5rem (24px), Line-height 1.3
  - `Body`: 1rem (16px), Line-height 1.5
  - `Caption`: 0.875rem (14px), Line-height 1.4
## Component Stylings & Layout Principles
- **Border Radius:** 
  - `rounded-sm`: `6px` for small badges and input fields
  - `rounded-md`: `8px` for cards, modals, and buttons
- **Elevation / Shadows:** 
  - Subtle dark drop shadow: `0 1px 3px 0 rgb(0 0 0 / 0.4), 0 1px 2px -1px rgb(0 0 0 / 0.2)`
- **Spacing Unit:** Based on an 8px grid system (`gap-2` = 8px, `gap-4` = 16px, `gap-6` = 24px).
- **Layout Structure:** Clean 12-column responsive layout with max-width container `1280px` and generous negative space (at least 25% open canvas).
## Do's and Don'ts (Strict Guidelines)
- **DO** maintain high WCAG AA/AAA contrast ratios between text and background surfaces in dark mode.
- **DO** keep cards clean with a maximum of 3 data points per card view.
- **DON'T** use heavy neon gradients or overly saturated background colors.
- **DON'T** mix more than two font families across the entire interface.
